# Runlet Studio

Редактор сайтов на Electron: HTML, CSS и JavaScript в трёх панелях, живой
предпросмотр, локальный Live Server, 3D-редактор, проекты и статический анализ
кода на Python. Интерфейс без неона, со встроенными SVG-иконками и понятной
группировкой инструментов.

---

## Запуск

```bash
npm install
npm start          # собрать рендерер и открыть десктопное приложение
```

Веб-версия (для предпросмотра в браузере):

```bash
npm run build && npm run web     # http://localhost:4173
```

Дистрибутив:

```bash
npx electron-builder
```

Нужен Python 3.8+ только для движка анализа (стандартная библиотека, без
дополнительных пакетов). Electron стоит в `optionalDependencies` — если бинарник
не скачался за прокси, выполните `npm install electron@45 --no-save`.

Окно приложения: 1680×1020, минимум 1280×800 — рассчитано на обычный ПК.
В настройках можно включить системную рамку окна вместо встроенной.

## Первый запуск

Вместо сразу открытого проекта вас встречает **меню проектов**: слева коротко
рассказано, как устроен редактор, справа — список проектов и создание нового.

- проекты можно создавать, называть, переименовывать, дублировать и удалять;
- шаблоны: пустой, демо, лендинг, форма, CSS 3D и Canvas;
- экспорт одного проекта или всех проектов в JSON, импорт из JSON;
- ZIP и одиночный HTML тоже импортируются (меню «Файлы»);
- галочка «показывать это меню при запуске» отключается в настройках.

Отдельно есть окно **«Как работать»** с шестью карточками: панели кода,
предпросмотр, анализ, Live Server, 3D и оконный режим. Его можно открыть в любой
момент кнопкой на панели действий.

## Интерфейс

Всё сгруппировано, а не свалено в одну кучу.

**Слева — вертикальная навигация с двумя секциями:**

- Проект: файлы, поиск, библиотеки, ассеты.
- Инструменты: 3D-редактор, уроки, плагины, карта идей.

**Центр — три редактора** (CodeMirror 6) с перетаскиваемыми разделителями,
mini-картой, хлебными крошками и подсветкой ошибок. Раскладки: три колонки,
три строки или вкладки.

**Справа — предпросмотр и нижняя панель.** В нижней панели пять вкладок:
Анализ, Консоль, Отладка, Инспектор (DOM / Сеть / Хранилище / Перфоманс) и
Журнал.

### Устройства

Только три понятных пресета без названий моделей:

| Кнопка | Размер | Что это |
| --- | --- | --- |
| Десктоп | 1280×800 | обычное окно ПК |
| Планшет | 820×1180 | вертикальный планшет |
| Телефон | 390×844 | вертикальный смартфон |

Плюс произвольный размер: просто введите ширину и высоту. Кнопка поворота
меняет ориентацию, зум вписывает страницу в панель.

## Live Server

Аналог расширения Live Server из VS Code, встроенный в программу.

Кнопка **Live Server** поднимает локальный HTTP-сервер и отдаёт файлы проекта
по настоящим адресам. Поэтому работают относительные пути, ES-модули,
CSS `@import` и `fetch()` к локальным файлам. При каждом изменении кода версия
проекта увеличивается, и открытая страница обновляется сама.

- В Electron сервер поднимается в главном процессе на `127.0.0.1:5500`
  (порт меняется в настройках).
- В веб-версии используется тот же origin, путь `/live/`.
- **«Сайт в окне»** открывает сайт в плавающем окне внутри программы.
- **«В браузере»** открывает сайт в системном браузере.

Сервер отдаёт только файлы текущего проекта; имена файлов проверяются на
`..`, абсолютные пути и служебные ключи.

## Оконный режим

Кнопка **«Оконный режим»** (Ctrl+Shift+W) выносит сайт, 3D-редактор и консоль
в отдельные плавающие окна. Окна перемещаются мышью, меняют размер,
сворачиваются и разворачиваются. Панели возвращаются на свои места при
закрытии окна.

Любой редактор тоже можно вынести в окно кнопкой в его заголовке, а панель
инспектора — через настройки. В Electron дополнительно доступен переключатель
системной рамки окна (приложение пересоздаёт окно с сохранением размера).

## 3D-редактор

Вкладка «3D» в левой навигации — компактный моделировщик на canvas без WebGL и
внешних библиотек.

- примитивы: куб, сфера, цилиндр, конус, плоскость, тор;
- добавление, выбор кликом, дублирование и удаление объектов;
- позиция, поворот и масштаб по осям, цвет, каркасный режим;
- вращение камеры мышью, зум колесом, сетка и оси;
- экспорт в проект: `scene.json` и самостоятельный `3d.html` со встроенным
  рендерером (открывается как обычная страница).

Шаблон «CSS 3D» создаёт проект с вращающимся кубом на чистом CSS — его можно
менять прямо в редакторе.

## Настройки

Окно настроек разделено на вкладки: Редактор, Предпросмотр, **Бинды**,
**Кнопки**, **Окна**, Вид, Хранилище, О программе.

### Бинды

Компактный список без лишних полей. У каждой команды две кнопки:

- **Назначить** — нажимаете нужное сочетание, оно сразу сохраняется;
- **Проверить** — появляется маленькое окно, вы нажимаете сочетание и видите,
  совпало оно или нет.

Полный список комбинаций не обязателен для понимания: достаточно того, что
любую можно переопределить прямо здесь.

### Кнопки

Панель действий собирается из заготовленных команд. В настройках каждая
позиция — это выпадающий список команд; стрелки меняют порядок, корзина
удаляет кнопку, «Добавить» вставляет новую из того же набора. Есть сброс к
стандартному набору. Так можно поставить свои кнопки вместо предложенных.

### Окна

Включение оконного режима, системная рамка, порт Live Server, показ меню
проектов при запуске и кнопки быстрого открытия окон.

## Дизайн

Стиль «Stecyl» — плоские стальные поверхности, спокойная иерархия, никаких
неоновых свечений и градиентных кнопок. Все пиктограммы — встроенный набор
SVG-иконок (`app/src/core/icons.js`), смайлики в интерфейсе не используются.
Темы: тёмная, светлая, контрастная и автоматическая; акцентный цвет и
плотность настраиваются.

Старый «ИИ-ассистент» удалён: без подключения к API он не приносил пользы.
Вместо него — детерминированные инструменты кода (каркас тестов,
документация из JSDoc, README, проверка безопасности, простой рефакторинг) и
человеческие пояснения в панели анализа.

## Анализ кода

Python-движок (`analysis/engine.py`) по-прежнему объясняет, что код скорее
всего делает, и находит ошибки: незакрытые теги, дубли `id`, обращение к
несуществующему селектору, проблемы CSS, уязвимые конструкции JS, битые ссылки.
Отчёт содержит оценку, пошаговый сценарий, список замечаний с автоисправлениями
и экспорт в Markdown/JSON.

Движок работает как отдельный процесс без сети и записи на диск. Если Python
недоступен, включается встроенный JS-анализатор.

## Безопасность

Сохранены все наработки из PR #2: Electron 45, `npm audit` без уязвимостей,
sandbox рендерера, проверка путей IPC, токен для локального REST API,
валидация заданий для Python-движка, изоляция предпросмотра и плагинов, защита
ссылок-шаринга и zip-slip. Подробности — в истории коммитов и в
`scripts/security.mjs`.

Live Server добавляет два публичных эндпоинта только для чтения:
`/live/*` и `/live/__version`. Изменение проекта требует токен.

## Тесты

```bash
npm audit     # 0 уязвимостей
npm test      # 20 групп проверок + 39 security-проверок
```

Тесты поднимают собственный сервер на отдельном порту, проверяют сборку,
Python-движок, запуск интерфейса в jsdom, 102 команды подряд, валидность
`srcdoc`, мост предпросмотра и сценарии безопасности.
