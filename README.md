# Runlet Studio

Редактор сайтов на Electron: HTML, CSS и JavaScript в трёх панелях, живой
предпросмотр, локальный Live Server, 3D-редактор, проекты и статический анализ
кода на Python. Плоский интерфейс без неона, встроенные SVG-иконки, крупный
читаемый код и обычное окно приложения, которое можно свернуть.

---

## Запуск

```bash
npm install
npm start          # собрать рендерер и открыть десктопное приложение
```

Веб-версия:

```bash
npm run build && npm run web     # http://localhost:4173
```

Дистрибутив: `npx electron-builder`. Нужен Python 3.8+ только для анализа
(стандартная библиотека). Окно приложения: 1680×1020, минимум 1280×800.

---

## Что исправлено в этой версии

### Обычное окно программы

Приложение больше не требует полноэкранного режима. В браузере и Electron без
системной рамки оболочка превращается в нормальное окно с кнопками
**свернуть / развернуть / закрыть** в заголовке. Свёрнутое окно оставляет
панель задач снизу, закрытое — рабочий стол с кнопкой возврата. В Electron по
умолчанию включена **системная рамка** (настоящие кнопки ОС); переключатель —
в Настройки → Окна.

### Окно больше не дёргается само

Исправлен цикл самопроизвольного сворачивания/разворачивания: при старте
рендерер больше **никогда не вызывает** `setFrame()`, главный процесс читает
сохранённый выбор рамки из своего файла настроек до создания первого окна, а
рендерер только узнаёт это значение через `frameStatus`. Убрано автоматическое
восстановление плавающих окон и 3D-сцены при запуске, устранён двойной запуск
команд из выпадающих меню (из-за него переключатели мгновенно откатывались),
добавлены защиты от повторных `windowControl`. Регрессионный тест
`scripts/window-stability.mjs` проверяет 25 сценариев, включая Electron с
сохранённым безрамочным режимом.

### Панель инструментов разгружена

Вместо 15+ кнопок на виду только частое: **Запустить**, **Сохранить**,
**Анализ кода** и масштаб кода. Всё второстепенное сгруппировано в два меню —
**Файл** (проекты, создание, импорт, экспорт, диск) и **Ещё** (редактор,
инструменты, вид, справка). Пункты меню и действия над файлами дублируются в
контекстном меню по правому клику в дереве проекта.

Вкладка **«Идеи»** удалена из интерфейса. Инструменты сгруппированы в
вертикальной навигации (Проект / Инструменты), а DOM, сеть, хранилище и
перфоманс — в под-вкладки «Инспектор».

### Код читается

- шрифт редактора **16px**, межстрочный интервал **1.55** (настраиваются);
- **перенос длинных строк включён по умолчанию**, горизонтальная прокрутка
  тоже работает — код больше не обрезается;
- масштаб меняется кнопками `− / +` на панели, колесом мыши с Ctrl и в
  настройках; переключатель переноса строк — рядом;
- **Ctrl + колесо** меняет размер шрифта на лету.

### Контраст по WCAG

Пересмотрены все цветовые пары тёмной и светлой темы: основной текст,
второстепенный текст, номера строк, неактивные вкладки, иконки, подписи
статус-бара и цвета статусов. Автоматические проверки в `npm test` считают
коэффициенты и требуют ≥ 4.5:1 для текста и ≥ 3:1 для крупных элементов
(фактически 5.3–17.8:1). Кнопка «Проверить контрастность интерфейса» в
настройках показывает живой отчёт по текущей теме.

### Панель анализа

Круговой индикатор увеличен до 104px с крупной цифрой и анимацией заполнения.
Вместо шести мелких шкал — **три большие цветные карточки**: ошибки (красный),
предупреждения (жёлтый), советы (синий). Шаги, диагностики и кнопки получили
больше «воздуха», шрифт крупнее, а качество по направлениям вынесено в
отдельные двухколоночные шкалы с цветовой кодировкой.

### 3D-редактор работает

Раньше он пытался жить в 200-пиксельной панели и не рисовал — теперь это
**отдельная большая сцена** с гарантированным размером холста: открывается по
кнопке «3D», из меню или командой. Рендер идёт непрерывно, пока сцена видима,
поэтому примитивы точно появляются. Куб, сфера, цилиндр, конус, плоскость, тор;
позиция, поворот, масштаб, цвет, каркас, орбита камеры мышью и стрелками, зум
колесом. Экспорт в `scene.json` и самодостаточный `3d.html`.

### Нормальная файловая система

Дерево с настоящими вложенными папками: раскрытие по стрелке, SVG-иконки типов
файлов, размер, контекстное меню. Кнопки быстрого создания **HTML / CSS / JS**,
диалог создания с выбором типа, имени, папки и шаблона (HTML5, карточка, форма,
hero, CSS reset, JS-модуль…). Можно открыть реальную папку с диска и сохранить
проект на диск (Electron), а в браузере — загрузить папку и скачать ZIP.

### Анимации

Плавное появление панелей, модалок, меню, тостов и карточек меню проектов,
микроанимации кнопок и строк дерева, анимированное кольцо оценки. Уважается
`prefers-reduced-motion`, а в настройках есть выключатель анимаций.

## Первый запуск

Вместо сразу открытого проекта вас встречает **меню проектов** (1180×760):
слева коротко рассказано, как устроен редактор, справа — создание проекта
(имя + 6 шаблонов) и список проектов с открытием, переименованием,
дублированием, удалением. Экспорт одного проекта или всех в JSON, импорт
проектов, ZIP и одиночного HTML. Окно «Как работать» доступно в любой момент.

## Интерфейс

- **Слева** — вертикальная навигация: Проект (файлы, поиск, библиотеки,
  ассеты) и Инструменты (3D, уроки, плагины).
- **Центр** — три редактора CodeMirror 6 с перетаскиваемыми разделителями,
  мини-картой и подсветкой ошибок. Раскладки: три колонки, три строки, вкладки.
- **Справа** — предпросмотр и нижняя панель: Анализ, Консоль, Отладка,
  Инспектор (DOM / Сеть / Хранилище / Перфоманс) и Журнал.
- **Устройства** — три понятных пресета: Десктоп 1280×800, Планшет 820×1180,
  Телефон 390×844, плюс произвольный размер.

## Live Server

Аналог расширения VS Code: локальный HTTP-сервер отдаёт файлы проекта по
настоящим адресам (относящиеся пути, ES-модули, CSS `@import`, `fetch()`), при
изменении кода страница обновляется сама. В Electron — нативный сервер на
`127.0.0.1:5500`, в веб-версии — `/live/*`. Кнопки: «Сайт в окне» (плавающее
окно внутри программы) и «В браузере».

## Оконный режим панелей

Любой редактор можно вынести в отдельное плавающее окно кнопкой в его
заголовке; сайт, 3D и консоль выносятся режимом «Оконный режим». Окна
перетаскиваются, меняют размер, сворачиваются и возвращают панели на место.

## Настройки

Вкладки: Редактор, Предпросмотр, **Бинды**, **Кнопки**, **Окна**, Вид,
Хранилище, О программе.

- **Бинды** — компактный список, у каждой команды «Назначить» и «Проверить».
- **Кнопки** — панель действий собирается из заготовленных команд: замена,
  порядок, добавление, удаление, сброс.
- **Окна** — оконный режим приложения, системная рамка, панели в окнах, порт
  Live Server, анимации и меню проектов при запуске.

## Анализ кода

Python-движок (`analysis/engine.py`) объясняет, что код делает, и находит
ошибки: незакрытые теги, дубли `id`, обращение к несуществующему селектору,
проблемы CSS, уязвимые конструкции JS, битые ссылки. Отчёт — оценка,
пошаговый сценарий, замечания с автоисправлениями, экспорт Markdown/JSON.
При отсутствии Python включается встроенный JS-анализатор.

## Безопасность

Сохранены наработки PR #2: Electron 45, `npm audit` без уязвимостей, sandbox
рендерера, проверка путей IPC, токен REST API, валидация заданий Python-движка,
изоляция предпросмотра и плагинов, защита ссылок и zip-slip. Чтение папки и
запись проекта на диск идут через проверенные IPC-обработчики с ограничением
путей, размеров и количества файлов.

## Тесты

```bash
npm audit     # 0 уязвимостей
npm test      # 30 групп проверок, 38/38 jsdom-проверок, 102 команды, 39 security
```

Проверяются сборка, Python-движок, запуск UI, контраст WCAG обеих тем,
читаемость кода, работа 3D-сцены, файловая система, оконный режим, анимации,
Live Server E2E и сценарии безопасности.
